# 0.1.1 发行材料包

本轮范围：准备材料与隔离环境验收。用户于 2026-10-26 明确“只准备材料”；不执行机外签名备份、真机耗电、证书申请、公证、商店上传或公开发布。自动更新不作为开发目标，后续采用手动下载安装包。

## 渠道文案

名称：s-light notes

短描述：本地 Markdown 笔记，支持设备间 P2P 同步与桌面便签。

详细描述：无需应用账号即可创建、编辑、搜索和整理 Markdown 笔记。桌面端可将笔记打开为便签并置顶，设置全局新建便签快捷键，导入文件或导出带摘要清单的备份。Android 使用独立移动界面，支持设备码与二维码配对、回收站和有界后台同步。启用同步后，共享内容在用户配对的设备间交换；离线时仍可编辑，发生竞争修改时保留冲突副本。

限制说明：同步不能代替独立备份；Markdown 导出不含回收站、设置和同步身份。不同系统的后台调度和输入法行为需要对应设备验收。当前发行准备不承诺自动更新、账号云服务或自动冲突合并。

候选说明：0.1.1 在 0.1.0 基础上补充签名升级、真实 Android/容器同步、中文组合输入、原生文件规模检查及 Windows/Linux 安装版验收。通过范围以 `V2_TEST_PLAN.md` 的最终记录为准；本材料不单独宣称全部平台真机通过。

## 原生与真机验收操作单

每次只用两条虚构笔记；物理设备、Parallels 或 Mac 真机执行前另获授权。保存包摘要、设备/系统版本、配置、预期、实际和日志位置。

| 场景 | 操作 | 通过标准 |
| --- | --- | --- |
| Android 输入法 | 拼音组合、候选选择、换行、撤销；组合时返回/切换 | 无半成品落盘、丢字或旧保存覆盖新输入 |
| 扫码与权限 | 拒绝相机后手动配对；允许后扫描测试码；重建 Activity 后再请求 | 可恢复，权限拒绝不影响离线编辑 |
| 后台与通知 | 拒绝/允许通知；开启后离开应用；从通知停止 | 有可见通知，用户可停止，引擎不遗留 |
| 两台安装版设备 | 手动/扫码互配，双向修改、断网竞争修改、重连 | 原文完整，冲突两版本可找回，既有系统 Syncthing 不被停止 |
| Mac 快捷键/登录自启 | 从另一个应用触发；真实注销登录 | 只触发一次，保存后退出，按设置启动 |
| 手动升级 | 同签名原地安装，再冷启动 | 笔记、回收站、设备身份、文件夹和配对保留 |
