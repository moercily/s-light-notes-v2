# 隐私声明草案

适用候选版本：0.1.1。编制日期：2026-10-26。
本文件是本轮准备的发行材料，尚未作为正式隐私政策发布。发行主体、适用渠道、生效日期和非公开联系渠道由发行者补充确认。

## 笔记与设备数据

s-light notes 无需注册应用账号。桌面笔记保存在本机 Markdown 目录；Android 笔记位于应用私有文件目录。文件在本机以普通文件保存，应用未额外提供笔记静态加密；设备锁定和磁盘加密由操作系统管理。

启用 P2P 后，Syncthing 将共享文件夹的文件内容、文件名及同步所需的修改时间、版本和索引信息发送给你配对并共享该文件夹的设备。普通笔记、冲突副本和共享目录下未排除的文件均可能参与同步；应用回收站位于笔记目录的 `.trash` 下，不能把“移入回收站”理解为撤回所有远端副本。配对设备可保留它已经接收的内容。

设备证书、私钥、API 凭据和同步配置保存在独立的应用数据目录，默认不放进笔记共享文件夹。设备码用于识别设备，并非账号密码；不要公开完整配置、私钥或 API 凭据。

## 网络连接与第三方

- 同步由内置 Syncthing v2.1.2 执行。设备间传输使用 TLS 并校验配对身份；传输加密不等于本机文件加密。
- 正常产品配置沿用 Syncthing 的发现和中继选项。全局发现服务可能接收设备 ID、外部 IP 和监听端口；本地发现会在局域网广播设备 ID 和端口；使用中继时，中继运营者可观察连接相关元数据。不要把本项目描述为“从不连接公共服务”或“仅局域网同步”。
- 本项目未接入独立的应用广告或行为分析 SDK。Syncthing 上游默认使用报告为未同意状态；其默认崩溃报告选项为开启，本项目当前未统一覆盖该选项。正式渠道的“收集/共享诊断数据”填报需按实际分发包和引擎配置确认，不能填写笼统的“零数据收集”。
- 打开笔记里的外部链接，或加载外部图片时，相应站点可能获得网络请求信息；这些站点使用自己的隐私政策。
- 离线编辑不需要连接同步对端。可在同步中心停止引擎，并关闭机会同步和离开应用后继续同步。

其中网络服务行为依据 [Syncthing 安全说明](https://docs.syncthing.net/users/security.html)；默认崩溃/使用报告选项另核对了固定 v2.1.2 引擎的隔离配置。测试夹具关闭公共发现、中继、NAT、使用报告和崩溃报告，这不是产品默认配置承诺。

## Android 权限与后台

| 权限/系统能力 | 使用目的 | 用户可用的替代方式 |
| --- | --- | --- |
| 网络访问 | 设备发现与笔记同步 | 关闭同步，继续离线编辑 |
| 附近 Wi-Fi 设备（API 36） | 按系统要求访问局域网对端 | 拒绝后仍可离线编辑 |
| 相机 | 扫描另一台设备的二维码 | 手动输入设备码 |
| 通知、数据同步前台服务 | 用户选择离开应用后继续同步时显示通知 | 不开启持续后台会话 |
| 系统文档选择器 | 用户主动选择导入、导出或授予的笔记访问 | 不执行相应操作 |

机会同步默认只使用非计费网络，并要求电量不低；系统决定具体调度时间。持续后台会话默认关闭。应用不申请读取联系人、短信或定位权限。

## 保存、删除与备份

应用没有中央笔记服务器或云端账号删除入口。你可以在应用中将笔记移入回收站，再执行永久删除；配对设备上的保留副本、用户导出的备份和系统备份需要分别处理。卸载 Android 应用可能清除其私有数据，卸载前先导出需要保留的笔记。

桌面 Markdown 导出包含普通笔记、冲突副本和摘要清单，不包含回收站、设置、同步证书或私钥。完整迁移还需单独备份这些数据。同步会传播修改和删除，不能代替独立备份。
