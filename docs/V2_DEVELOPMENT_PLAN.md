# s-light notes v2 开发计划

更新：2026-10-25。本计划以当前代码和 `V2_TEST_PLAN.md` 的证据为准。
`[x]` 代表相应范围已验证；构建、自动化测试、安装包交互验收分别记录。
旧检查点保留在测试计划和 Git 历史中，不再把已经完成的 Android 扫码列为待实现。

## 当前基线

- 本地优先，普通 Markdown 文件，Tauri 桌面端与 Android 独立界面。
- 已有笔记增删改、回收站、搜索、深浅色、桌面便签、置顶、快捷键及四类设置。
- Syncthing v2.1.2 引擎、设备码/二维码配对、Android 有界后台同步均已实现。
- Android 与桌面此前完成 arm64 真机双向同步、离线恢复及冲突功能验收；不自动延伸为新版本真机通过。
- 公开发布仍为 `0.0.1`，Mac arm64 DMG 与 Windows x64 EXE 均已确认存在。
- 当前开发版本 `0.1.0`：包含可靠性修复、桌面导入导出和编辑器外观设置。
