# s-light notes v2 开发计划

更新：2026-10-26。本计划以当前代码和 `V2_TEST_PLAN.md` 的证据为准。
`[x]` 代表相应范围已验证；构建、自动化测试、安装包交互验收分别记录。

## 当前基线

- 本地优先，普通 Markdown 文件，Tauri 桌面端与 Android 独立界面。
- 已有笔记增删改、回收站、搜索、深浅色、桌面便签、置顶、快捷键及四类设置。
- Syncthing v2.1.2 引擎、设备码/二维码配对、Android 有界后台同步均已实现。
- Android 与桌面此前完成 arm64 真机双向同步、离线恢复及冲突功能验收；不自动延伸为新版本真机通过。
- 公开发布仍为 `0.0.1`，Mac arm64 DMG 与 Windows x64 EXE 均已确认存在。
- 当前开发版本 `0.1.1`：包含可靠性修复、桌面导入导出和编辑器外观设置。

## 后续实施顺序与外部依赖

1. 采用 [无界面测试入口](HEADLESS_TESTING.md)，默认只跑与当前改动相关的少量容器测试；QEMU 使用 ARM64 原生虚拟化，不重复执行昂贵的 x64 全系统模拟。
2. Windows/Linux 原生交互及第二台桌面验收仍单独记录。需要本机 Parallels 或 Mac 真机时先询问用户，不弹出测试窗口打断使用。
3. 使用独立介质备份 Android 签名身份；连接真机完成本版回归与耗电测试。
4. P3 本轮只准备发行材料；机外备份、真机耗电、正式签名/公证与商店上传留给后续明确授权的发行流程。自动更新不进入待办。
5. iOS、账户系统、云服务和自动冲突合并不纳入此次实施。

禁止根据模拟测试标记硬件验收完成；不能用构建通过替代运行通过。

## 本轮 P0～P3 执行范围

- P0：签名 Android 0.1.0 → 0.1.1，原生 UI 配对隔离 Docker ARM64 对端，实际双向传输、离线竞争修改、升级后身份/绑定/配对和独立退出。两条初始笔记，不访问用户数据。
- P1：远端 Windows 原生 VM 与 Linux Xvfb 安装版编辑、便签、原生置顶、跨应用快捷键与退出检查；仅测试脚本变化时复用带摘要清单的安装包。Mac、Parallels 和真实登录验收未纳入无窗口通过范围。
- P2：无窗口 Android WebView 的真实 InputConnection 中文组合输入，以及 200 个原生 Markdown 文件和长笔记；记录自动化观察开销，不冒充低端真机或千条笔记结论。
- P3：用户确认本轮“只准备材料”。提供 [发行材料包](RELEASE_MATERIALS_0.1.1.md) 和 [隐私草案](PRIVACY_DRAFT.md)，其中包含签名备份恢复、真机/后台耗电方案及渠道待补信息，不执行这些外部流程。

最终结果、具体构建和运行编号记录在 `V2_TEST_PLAN.md`；失败用例修正后重跑，未验证项不自动勾选。
